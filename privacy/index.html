This Privacy Policy describes how Sixty Drive Control handles information when its owner authorizes access to Google Drive.

Information accessed

The application may access Google Drive files and file metadata required to read, create, update, or synchronize files used by the application's control and runtime-status workflow.

How information is used

Google Drive data is used only to provide synchronization functionality requested by the account owner. The application does not use Google Drive data for advertising, profiling, or unrelated purposes.

Sharing and sale of data

The application does not sell Google user data. It does not share Google user data with advertisers or data brokers. Data is processed only as necessary to operate the owner's synchronization workflow and the services chosen by the owner to run that workflow.

Storage and security

Authorization credentials and runtime files are stored only in systems controlled by the application owner. Reasonable technical measures are used to restrict access to credentials and project data.

Retention and deletion

Files remain in Google Drive or the owner's systems until the owner deletes them or removes the application's access. The owner can revoke Google account access at any time from Google Account security settings.

Changes

This policy may be updated if the application's data practices change. The current version will remain available at this URL.
