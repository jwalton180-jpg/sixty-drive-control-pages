Sixty Drive Control

HomePrivacyTerms

Sixty Drive Control is a private, single-user utility used by its owner to synchronize application control files and runtime-status files with Google Drive.

The application uses Google Drive only to read and write files needed for this synchronization workflow. It is not offered as a public consumer service and does not sell or broker access to Google user data.

Google Drive access

Google Drive access is used to synchronize files selected for the application's control and runtime-status workflow. Access is initiated and authorized by the Google account owner.

Contact

Questions about this application can be directed to the developer through the GitHub account that publishes this site.
